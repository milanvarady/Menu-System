# drawSetText

<span class="badge badge-secondary">function</span>

```gml
drawSetText(col, font, [halign], [valign])
```

## Description
Changes drawing color, font and alignment in one line

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| col | `color` | Color |
| font | `font` | Font |
| halign | `font_alignment` | Horizontal alignment (default: fa_centre) |
| valign | `font_alignment` | Vertical alignment (default: fa_middle) |
