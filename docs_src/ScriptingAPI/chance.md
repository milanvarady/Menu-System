# chance

<span class="badge badge-secondary">function</span>

```gml
chance(percent)
```

## Description
Returns true or false based on the chance

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| percent | `float` | Chance as a float, so 0% is 0.0, 75% is 0.75, and 100% is 1.0 |
