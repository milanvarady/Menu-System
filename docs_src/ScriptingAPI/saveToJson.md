# saveToJson

<span class="badge badge-secondary">function</span>

```gml
saveToJson(struct/array)
```

## Description
Saves a stuct/array nested datat structure to a file.

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| struct | `struct/array` | /array The stuct/array nested datat structure to be saved |
| filename | `string` | The name under the file will be saved |

## Returns
`undefined` N/A
