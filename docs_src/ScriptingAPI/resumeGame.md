# resumeGame

<span class="badge badge-secondary">function</span>

```gml
resumeGame([keep_menu_active])
```

## Description
This function resumes the game

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| keep_menu_active | `bool` | If true the menu will remain active after resuming the game (default: false) |

## Returns
`undefined` N/A

## Example
resumeGame(true);
