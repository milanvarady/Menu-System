# inRange

<span class="badge badge-secondary">function</span>

```gml
inRange(val, min, max)
```

## Description
Checks if a value is in a certain range

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| val | `real` | The value being checked |
| min | `real` | Bottom range |
| max | `real` | Top range |

## Returns
`bool`
