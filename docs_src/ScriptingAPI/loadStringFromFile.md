# loadStringFromFile

<span class="badge badge-secondary">function</span>

```gml
loadStringFromFile(filename)
```

## Description
Loads a string from a file. If the file does not exists retruns undefined.

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| filename | `string` | The file to load |

## Returns
`string/undefined`
