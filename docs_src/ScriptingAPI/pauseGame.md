# pauseGame

<span class="badge badge-secondary">function</span>

```gml
pauseGame([active_objs])
```

## Description
This function pauses the game.

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| active_objs | `array` | (optional) The list of objects to keep active after pausing |

## Returns
`undefined` N/A

## Example
pauseGame([oMenu, oInputManager]);
