# drawText

<span class="badge badge-secondary">function</span>

```gml
drawText(x, y, str, [scale], [outline_col])
```

## Description
Draws text with a certain scale and outline

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| x | `real` | Text x position |
| y | `real` | Text y position |
| str | `string` | String to be drawn |
| scale | `real` | Text scale (default: 1) |
| outline_col | `color` | The color of the outline or if nothing is passed in no outline will be drawn |

## Returns
`undefied` N/A
