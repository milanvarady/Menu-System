# menuSetPreset

<span class="badge badge-secondary">function</span>

```gml
menuSetPreset(preset)
```

## Description
Switches menu preset

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| preset | `real` | The preset to swich to, indexing starts from 0. |

## Returns
`undefined` N/A

## Example
menuSetPreset(e_menu_presets.pause_menu);
