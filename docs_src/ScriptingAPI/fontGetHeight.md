# fontGetHeight

<span class="badge badge-secondary">function</span>

```gml
fontGetHeight(font, [scale])
```

## Description
Gets a fonts height. Might not be 100% accurate!

## Arguments
| Name | Type | Description |
| ---- | ---- | ----------- |
| font | `font` | The font to get the height of |
| scale | `real` | (Optional) Font height will be mulitiplied with this number (default: 1) |
